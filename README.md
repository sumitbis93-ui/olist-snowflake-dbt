# End-to-End Snowflake & dbt Data Engineering Project

Built an end-to-end ELT pipeline using the Brazilian Olist e-commerce dataset, with AWS S3 as the source layer, Snowflake as the cloud data warehouse, dbt for transformation and data modelling, and Apache Airflow for workflow orchestration.

The project implements a layered dbt architecture consisting of staging, intermediate, and marts, with SQL-based transformations, analytical fact and dimension models, automated data-quality tests, snapshots for change tracking, and incremental processing patterns.
